Step 1 · JavaScript module

Write a reviewed handler

The implementation remains in a normal module. Registering it adds a labelled Function card to this editor only. 

const measure = (event) => {
  console.log(event.detail.data.size);
  console.log(event.detail.metadata.sourceEvent);
};

editor.registerFunction("CustomHandlers.Measure", measure, {
  label: "Measure recording",
  description: "Reports the recorded Blob size",
});

// HTML stores the stable reference, never the function body:
handler="CustomHandlers.Measure(event)"
