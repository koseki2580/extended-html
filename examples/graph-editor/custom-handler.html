Step 1 · JavaScript module

Write a reviewed handler

The implementation remains in a normal module. Only its stable namespace is exposed to declarative markup. 

globalThis.CustomHandlers = {
  Measure(event) {
    const blob = event.detail.data;
    console.log(blob.size, event.detail.metadata.sourceEvent);
    appendResult("Measure", event);
  },
};

// The editor stores this reference, not the function body:
handler="CustomHandlers.Measure(event)"

Step 2 · Declarative connection

Wire it in the editor

The initial Measure action is runnable. Add an Audit path to see one event safely invoke multiple application functions.
