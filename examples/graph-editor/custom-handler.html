Write normal JavaScript, register it with one editor, and connect browser data to it visually. A returned value flows into the next function without extra input or output elements.

Step 1 · JavaScript module

Write a reviewed handler

The implementation remains in a normal module. Registering it adds a labelled Function card to this editor only. To use your own function, edit the module, register it, reload this page, then select its source and choose the new card.

Open the editable JavaScript module 
const measure = (event) => ({
  size: event.detail.data.size,
  type: event.detail.data.type,
});
const label = (event) => ({
  ...event.detail.data, // measure's output
  label: "Review",
});

editor.registerFunction("CustomHandlers.Measure", measure, {
  label: "Measure recording",
  description: "Returns the recorded Blob summary",
});
editor.registerFunction("CustomHandlers.Label", label, {
  label: "Label summary",
});

// HTML stores the stable reference, never the function body:
<graph-action id="measure-chunk" from="chunk-ready"
  handler="CustomHandlers.Measure(event)"></graph-action>
<graph-action from="measure-chunk"
  handler="CustomHandlers.Label(event)"></graph-action>
